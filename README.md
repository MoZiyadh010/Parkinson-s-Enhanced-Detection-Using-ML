# Parkinson-s-Enhanced-Detection-Using-ML 

This project focuses on detecting Parkinson's disease using machine learning models, leveraging both **voice analysis** and **handwriting-based tests** to enhance accuracy. The goal is to develop a robust, non-invasive diagnostic tool that can assist in early detection and monitoring of Parkinson's disease.  

## Features  
✅ **Voice Analysis**: Extracts key speech biomarkers to detect tremors and vocal impairments.  
✅ **Handwriting Analysis**: Evaluates stroke consistency and tremor patterns in handwritten text.  
✅ **Machine Learning Models**: Utilizes deep learning techniques for classification and prediction.  
✅ **Slant deviation & Geometric evaluation**: Implements advanced analysis for reliable detection.  
✅ **Data-Driven Insights**: Provides evaluation metrics and visualization for model performance. 

**🚀 Developed with a passion for AI & Healthcare!**
## Technologies Used  
- Python (NumPy, Pandas, Matplotlib)  
- Machine Learning (Scikit-learn, TensorFlow/PyTorch)  
- Feature Extraction (MFCCs for voice, Image Processing for handwriting)
